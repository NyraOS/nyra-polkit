# Security policy

nyra-polkit decides which actions users and programs may take on a Nyra OS machine, so we take
reports seriously and handle them privately.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).

Include what you found, how to reproduce it, and the commit you tested. We will confirm the report,
keep you informed, and credit you in the fix unless you prefer otherwise.

## Supported versions

The project is in early development: only the latest release
([GitHub Releases](https://github.com/NyraOS/nyra-polkit/releases)) and the `main` branch are
supported.
